# 오른쪽 풍경 SVG

`index.html` 안에 인라인으로 들어 있습니다. 애니메이션은 전부
`styles.css` 아래쪽 "풍경" 구역에 있습니다. 외부 라이브러리 없음.

## 만들고자 한 그림

뒤에 큰 산 하나, 산 중턱에 한옥 한 채, 그 앞에 텃밭, 맨 앞에 개울.
바람에 풀과 나무가 산들산들 흔들리고, 개울에는 물고기가 유유히 헤엄치고,
맑은 가을 하늘에 뭉게구름과 새가 지나갑니다.

## 좌표 구조

`viewBox="0 0 300 450"` (세로 2:3). 위에서 아래로 층이 쌓입니다.

| y | 무엇 |
| --- | --- |
| 0 – 215 | 하늘 (`clipSky` 로 구름·새를 가둠) |
| 167 – 340 | 큰 산. 정상 `(118, 167)` |
| 243 – 296 | 한옥 |
| 314 – 384 | 텃밭 |
| 372 – 450 | 개울 (`clipWater` 로 물결·물고기를 가둠) |

그리는 순서가 곧 앞뒤 순서입니다. 뒤엣것부터 씁니다.

## 산

**좌우 대칭이면 인공적으로 보입니다.** 정상을 왼쪽(`x=118`)으로 치우치게
두고, 오른쪽 비탈을 더 길고 완만하게 뺐습니다.

- 본체 한 장 + 능선 오른쪽 **그늘** 한 장으로 입체감을 냅니다. 그늘의
  경계선이 곧 능선이라, 세로로 곧게 그으면 접힌 종이처럼 보입니다 —
  비스듬히 내려오게 하세요
- 왼쪽 능선 위에 옅은 하이라이트 한 조각
- 골짜기 자국(가는 선 몇 개)이 없으면 평평한 색면으로 보입니다
- 산자락이 화면 좌우 끝에 닿아야 "큰 산"으로 읽힙니다. `x=0`, `x=300`
  에서의 높이가 텃밭보다 충분히 위에 있어야 합니다. 한 번 좁게 그렸다가
  둔덕처럼 보여서 다시 넓혔습니다

## 한옥

`translate(186,290) scale(0.82) translate(-150,-278)` 로 감싸서 위치와
크기를 한 번에 조절합니다. **집 자체 좌표는 건드리지 말고 이 transform만
바꾸세요.** 앞의 `translate(x, y)` 가 집이 앉을 자리입니다.

지붕 모양을 여러 번 고쳤습니다. 걸렸던 것들:

- 초승달 모양(위·아래 둘 다 곡선)으로 그리면 **아치·UFO처럼** 보입니다.
  위 가장자리만 곡선, 아래는 거의 직선이어야 지붕 덩어리로 읽힙니다
- 지붕이 높으면 **버섯**이 됩니다. 폭 100에 높이 24 정도로 납작하게
- 처마 끝이 살짝 들려야 한옥입니다 — 아래 가장자리를 가운데가 처지게
  그리면 양 끝이 상대적으로 올라갑니다
- 용마루를 좁게 그리면 굴뚝 상자처럼 보입니다. 지붕 윗변만큼 넓게

## 텃밭

- 모종(`#sprout`)에 줄기를 길게 그리면 **작은 나무**처럼 보입니다. 잎이
  낮게 퍼진 타원 세 개면 충분합니다
- 이랑 선은 아래로 갈수록 굵게(2 → 3.2) 해서 원근을 흉내 냅니다
- 모종을 격자로 배치하면 무늬처럼 보입니다. x를 불규칙하게, 뒤쪽 줄은
  작게(`scale(0.8)`) 앞쪽 줄은 크게(`scale(1.16)`)

## 개울

- 물결은 흰 선 세 묶음이 서로 다른 지연으로 흘러갑니다
- 물고기 세 마리. `#fish` 를 `<use>` 로 재사용하고 크기만 다르게

## 애니메이션

| 클래스 | 움직임 | 주기 |
| --- | --- | --- |
| `.sway` | 밑동을 축으로 ±1.7° 회전 | 2.7 – 9.1s |
| `.cloud` | 가로로 흘러감 | 96 – 168s |
| `.bird` | 가로지름 + `.wing` 이 `scaleY` 로 날갯짓 | 36 – 52s / 0.74 – 1.15s |
| `.ripple` | 가로 이동 + 페이드 | 6s |
| `.fish` | 가로지름 + `.bob` 이 위아래로 흔듦 | 28 – 37s |

각 요소는 `--dur`, `--d` (지연) 인라인 변수로 어긋나게 둡니다. **음수 지연**을
써서 처음부터 제각기 다른 위상으로 시작하게 했습니다 — 안 그러면 전부
같이 움직여서 기계처럼 보입니다.

### 꼭 기억할 것

SVG 요소를 회전·확대하려면 `transform-box: fill-box` 가 필요합니다. 없으면
기준점이 뷰박스 원점이 되어 요소가 화면 밖으로 날아갑니다.

```css
.scene .sway, .scene .wing, .scene .bob { transform-box: fill-box; }
```

그리고 **한 요소에 두 가지 움직임을 겹치지 마세요.** 이동과 날갯짓은
`transform` 이 충돌합니다. 바깥 `<g>` 가 이동하고 안쪽 `<g>` 가 변형하도록
중첩합니다 (`.bird > .wing`, `.fish > .bob`).
