# 오른쪽 풍경 SVG

`index.html` 안에 인라인으로 들어 있습니다. 애니메이션은 전부
`styles.css` 아래쪽 "풍경" 구역에 있습니다. 외부 라이브러리 없음.

## 만들고자 한 그림

가을 산골. 뒤로 겹겹이 물러나는 보랏빛 산, 단풍이 덮인 앞산, 그 아래
한옥 한 채, 앞으로 배추가 자란 텃밭과 나무 울타리, 맨 앞에는 조약돌이
비치는 개울. 바람에 나무와 풀이 산들산들 흔들리고, 개울에는 물고기가
유유히 헤엄치고, 하늘에는 뭉게구름과 새떼가 지나갑니다.

손그림 일러스트를 참고하되 **외곽선(잉크선)은 넣지 않습니다.** 면과 면의
명암 차이로만 입체를 만듭니다. 선처럼 보이는 것은 실제로 선인 것들
(나무 줄기, 억새, 물결, 기왓골)뿐입니다.

## 좌표 구조

`viewBox="0 0 300 450"` (세로 2:3). 위에서 아래로 층이 쌓입니다.

| y | 무엇 |
| --- | --- |
| 0 – 176 | 하늘 (`clipSky` 로 구름·새를 가둠) |
| 26 – 130 | 뭉게구름 세 덩이 |
| 100 – 146 | 새떼 세 무리 |
| 144 – 220 | 먼 산 두 겹 (보랏빛) |
| 198 – 270 | 단풍 든 앞산 + 그 위를 덮은 단풍 숲 덩어리 |
| 246 – 312 | 한옥이 앉은 언덕, 오솔길, 나무들 |
| 234 – 292 | 한옥 |
| 292 – 342 | 다랑논 |
| 317 – 358 | 텃밭, 배추, 나무 울타리 |
| 332 – 450 | 개울 (`clipWater` 로 물결·물고기·조약돌을 가둠) |

그리는 순서가 곧 앞뒤 순서입니다. 뒤엣것부터 씁니다.

## 한옥

`<g class="hanok">` 안에 있습니다. 위치·크기를 옮기려면 그룹 전체를
`transform="translate(x,y) scale(s)"` 로 감싸세요.

지붕 모양을 여러 번 고쳤습니다. **걸렸던 것들:**

- 위·아래 둘 다 곡선인 초승달로 그리면 **아치·UFO**가 됩니다
- 지붕이 높으면 **버섯**, 옆면이 둥글게 말리면 **돔**이 됩니다.
  결국 **각진 사다리꼴**이 정답이었습니다 — 처마 끝에서 마루 끝까지
  직선으로 올라가고, 마루는 수평
- 처마 끝이 살짝 들려야 한옥입니다. 아래 가장자리를 가운데가 처지게
  그리면 양 끝이 상대적으로 올라갑니다
- 용마루를 좁게 그리면 굴뚝 상자처럼 보입니다. 지붕 윗변만큼 넓게
- 담장은 집에서 떨어뜨려 놓으면 **허공에 뜬 흰 막대**로 보입니다. 축대에
  붙여 두세요

## 단풍나무

`#tree-o`(주황) `#tree-r`(빨강) `#tree-y`(노랑) `#pine2`(소나무). 밑동이
원점이라 `translate(x, 밑동y) scale(s)` 로 심으면 됩니다.

잎 덩어리는 **세 조각**입니다 — 본색, 아랫면 그늘, 윗면 하이라이트.
외곽선 없이 입체를 내는 방법입니다.

## 앞산의 단풍 숲

납작한 타원으로 얼룩을 주면 **사막**처럼 보였습니다. 능선을 따라 원을
줄줄이 얹어 **숲 덩어리**로 만드는 편이 훨씬 잘 읽힙니다.

## 텃밭

배추(`#cabbage`)를 줄지어 심고 앞에 나무 울타리를 둡니다. 모종에 줄기를
길게 그리면 작은 나무처럼 보이니, 잎이 낮게 퍼진 모양으로.

## 개울

물은 비스듬한 한 장입니다. 그 안에 조약돌 → 물결 → 물고기 순으로 얹고
`clipWater` 로 가둡니다. 물결선이 강의 방향과 나란해야 흐르는 느낌이
납니다.

## 애니메이션

| 클래스 | 움직임 | 주기 |
| --- | --- | --- |
| `.sway` | 밑동을 축으로 ±1.7° 회전 | 2.7 – 8.4s |
| `.cloud` | 가로로 흘러감 | 96 – 168s |
| `.bird` | 가로지름 + `.wing` 이 `scaleY` 로 날갯짓 | 36 – 52s / 0.74 – 1.15s |
| `.ripple` | 가로 이동 + 페이드 | 6s |
| `.fish` | 가로지름 + `.bob` 이 위아래로 흔듦 | 28 – 37s |

각 요소는 `--dur`, `--d` (지연) 인라인 변수로 어긋나게 둡니다. **음수 지연**을
써서 처음부터 제각기 다른 위상으로 시작하게 했습니다 — 안 그러면 전부
같이 움직여서 기계처럼 보입니다.

### 꼭 기억할 것

**1. `transform-box: fill-box`**

SVG 요소를 회전·확대하려면 필요합니다. 없으면 기준점이 뷰박스 원점이 되어
요소가 화면 밖으로 날아갑니다.

```css
.scene .sway, .scene .wing, .scene .bob { transform-box: fill-box; }
```

**2. 한 요소에 두 가지 움직임을 겹치지 말 것**

이동과 변형은 `transform` 이 충돌합니다. 바깥 `<g>` 가 이동하고 안쪽 `<g>` 가
변형하도록 중첩합니다 (`.bird > .wing`, `.fish > .bob`).

**3. 애니메이션이 붙은 그룹에 위치용 transform을 쓰지 말 것**

같은 이유로 덮어써집니다. 구름은 바깥 `<g class="cloud">` 가 흘러가고 안쪽
`<g transform="translate(0,52)">` 가 제자리를 잡습니다. 이걸 빠뜨려서 구름이
화면 위로 잘려 나간 적이 있습니다.

## 고칠 때

바꾸고 나면 크게 띄워서 봐야 합니다. 실제 표시 크기(318px)에서는 문제가
잘 안 보입니다. [workflow.md](workflow.md)에 SVG만 크게 띄워 스크린샷 찍는
방법이 있습니다.

색상 오타(`fill="#a08ko..."` 같은)는 브라우저가 조용히 무시해서 눈치채기
어렵습니다. 스크린샷 찍기 전에 한 번 훑으세요.

```sh
python3 -c "
import re
svg = re.search(r'<svg class=\"scene\".*?</svg>', open('index.html').read(), re.S).group(0)
print([v for v in re.findall(r'(?:fill|stroke|stop-color)=\"([^\"]+)\"', svg)
       if not (v=='none' or v.startswith('url(') or re.fullmatch(r'#[0-9a-fA-F]{3,8}', v))])
"
```
